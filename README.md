# NFT Marketplace

A modern, responsive NFT Marketplace dashboard built with React, Vite, and Tailwind CSS.

## Features

- Responsive NFT Marketplace Dashboard
- Dark Mode / Light Mode
- NFT discovery and browsing
- NFT Details page
- Active Bids
- Bids management
- Saved Items
- Collections
- User Profile
- Settings
- Search functionality
- NFT filtering
- Save / Unsave NFTs
- Place Bid functionality
- Bid removal
- Follow / Unfollow creators
- Add Money interaction
- Toast notifications
- Responsive mobile navigation
- Responsive desktop, tablet and mobile layouts
- Reusable React components
- React Router navigation

## Technologies

- React
- Vite
- Tailwind CSS
- React Router
- Lucide React Icons
- JavaScript
